# Minor Project - GroupDNA

## Project Title
GroupDNA - Hostel Boys Data Analysis

## Project Description
This minor project focuses on analyzing hostel boys' data using Python and data analysis techniques.

The project uses a Jupyter Notebook to perform data loading, data preprocessing, data cleaning, analysis, and visualization.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files in this Repository
- `GroupDNA_ipynb.ipynb` - Jupyter Notebook containing the project program and analysis.
- `hostel_bois.txt` - Dataset used for the project.

## Project Objectives
- Load and understand the dataset.
- Clean and preprocess the data.
- Perform data analysis.
- Generate useful insights from the dataset.
- Visualize the analyzed data using graphs and charts.

## How to Run
1. Download or clone this repository.
2. Open `GroupDNA_ipynb.ipynb` using Jupyter Notebook or Google Colab.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells sequentially.

## Conclusion
The project demonstrates the use of Python-based data analysis techniques to process hostel student data and obtain meaningful insights.
